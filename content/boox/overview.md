## BOOX 是什么

BOOX 是广州文石信息科技有限公司（Onyx International）推出的电纸书产品线。与 Kindle、Kobo 最大的不同在于：**BOOX 运行开放的 Android（安卓）系统**，用户可以自由安装第三方应用，而 Kindle 与 Kobo 运行封闭固件——这也是本站另外几篇教程存在的原因：

- [Kindle 5.x 软件越狱](/wiki/kindle/jailbreak/)、[Kindle Touch 越狱](/wiki/kindle/touch-jailbreak/)
- [Kobo Touch 破解入门](/wiki/kobo/hacking/)、[Kobo WiFi 破解入门](/wiki/kobo/wifi-hacking/)

在 BOOX 上，这些"越狱/破解"步骤大多不需要：装第三方阅读器（如 [KOReader](/wiki/software/koreader/)，其 Android 版可直接安装）、换字体、装笔记与办公应用，都是系统原生支持的操作。

市场地位方面：Kindle 于 2022–2023 年退出中国市场后，国产品牌填补了空缺。据公开报道，文石已于 2026 年 1 月向港交所递交上市申请，其招股材料披露 2024 年高速阅读器销量约 38.4 万台；在部分全球统计中，文石按零售价值已位居电子纸阅读器品牌前列（见[36氪报道](https://m.36kr.com/p/3711180856980230)、[华尔街见闻报道](https://wallstreetcn.com/articles/3765411)）。

## 产品线总览（截至 2026-11）

BOOX 官网将产品分为两大类，另有电子纸显示器产品线：

### 高速阅读器

6–7 英寸、以阅读为核心的机型（[官方分类页](https://zh.boox.com/series/?category=reading)）：

| 系列 | 定位 |
| --- | --- |
| P6 系列（P6+ / P6 Pro / P6 Pro C） | 7 英寸主力阅读器，带实体翻页键的图书阅读器形态 |
| Leaf 系列（Leaf 5 / Leaf 5C / Leaf 5+） | 7 英寸轻薄纯阅读，Leaf 5C 为彩色墨水屏 |
| Poke 系列（Poke7 / Poke7 Pro） | 6 英寸入门便携款 |

### 生产力平板

10–13.3 英寸、带电磁手写的大屏机型（[官方分类页](https://zh.boox.com/series/?category=ai_working)）：

| 系列 | 定位 |
| --- | --- |
| Note X 系列（Note X5 / X5S / X5 mini / Note X6） | 手写笔记与文档批注主力线 |
| Tab / T 系列（Tab 10C Pro / T10 C / T10C+ / T13 C） | 高刷新率彩屏，偏办公与多任务 |

### Mira 显示器

电子纸电脑显示器（[MiraPro C 彩屏版](https://zh.boox.com/product/?id=4408)等），连接电脑作为护眼外接屏使用。

## BOOXOS 系统特性

BOOX 设备当前搭载 **BOOXOS**（官方教程中以"文石 OS4"指代第 4 代系统），基于 Android 定制：

- **开放应用生态**：可安装 Android 应用——官方应用商店、第三方 APK，官方教程甚至包含 Google Play 的安装指引
- **刷新模式调节**：针对墨水屏特性的多档刷新模式，平衡残影与速度（"刷新模式区别与效果""NeoReader 刷新模式设置"等官方教程）
- **手写与笔记**：生产力平板系列标配电磁笔，支持全局手写、手写转文字、录音转文字等
- 儿童模式、悬浮球、桌面小部件等系统级功能均有官方教程

## NeoReader：官方阅读器

每台 BOOX 内置自研阅读软件 **NeoReader**，是 BOOX 阅读体验的核心：

- 支持主流电子书格式（PDF / EPUB / MOBI / TXT / DJVU / CBZ 等，格式知识见本站 [EPUB](/wiki/formats/epub/) 与 [MOBI](/wiki/formats/mobi/) 详解）
- 多档刷新模式与阅读样式调整（字号、字体、版式、边距）
- PDF / CAJ 文档的重排与版式调整、双页阅读
- 内置 OCR 识别与在线词典、划线高亮、笔记导出
- 256 灰阶优化（"图片平滑"功能）

## 中文用户的典型场景

开放安卓系统让 BOOX 在中文场景下有几个常见用法：

1. **第三方阅读 app**：微信读书、起点、晋江等均可安装——官方支持站甚至提供过晋江 app 的适配说明
2. **文献与办公**：大屏机型配合手写笔做 PDF 批注、会议记录（官方"会议笔记"教程）
3. **传书**：数据线连接电脑、局域网无线互传、BOOX 助手 app 均有官方教程——相比 Kindle 时代的推送方案直白得多

## 与 Kindle / Kobo 怎么选

| 需求 | 建议 |
| --- | --- |
| 只读书、追求省心与续航 | Kindle / Kobo（想折腾见本站[越狱](/wiki/kindle/jailbreak/)与[破解](/wiki/kobo/hacking/)教程） |
| 要装中文阅读 app、看网文 | BOOX（开放系统，开箱即用） |
| 手写笔记、PDF 文献批注 | BOOX Note / Tab 系列或同级国产大屏 |
| 预算有限 | 二手 Kindle / Kobo 仍是性价比之选，配合本站教程可玩性很高 |
