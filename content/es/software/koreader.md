KOReader es un visor de documentos para dispositivos de [tinta electrónica (E Ink)](https://wiki.mobileread.com/wiki/E_Ink) basados en [Linux](https://wiki.mobileread.com/wiki/Linux). Actualmente existen versiones para dispositivos [Kindle](https://wiki.mobileread.com/wiki/Kindle), [Kobo](https://wiki.mobileread.com/wiki/Kobo), [PocketBook](https://wiki.mobileread.com/wiki/PocketBook) y [Android](https://wiki.mobileread.com/wiki/Android).

## Visión general

Para instalar este producto necesitas hacer [jailbreak](/es/wiki/kindle/jailbreak/) a tu dispositivo, instalar un lanzador (launcher) y después instalar el lector. Podrás seguir usando el software Original antiguo o el nuevo software KOReader. Para Kobo todo este trabajo ya está hecho: la comunidad crea una versión especial de firmware que puede descargarse desde MobileRead.

## Características

- Plataformas compatibles: [Kindle Touch](https://wiki.mobileread.com/wiki/Kindle_Touch), [Kindle Paperwhite](https://wiki.mobileread.com/wiki/Kindle_paperwhite), [Kobo Glo](https://wiki.mobileread.com/wiki/Kobo_Glo), [Kobo Touch](https://wiki.mobileread.com/wiki/Kobo_Touch), [Kobo Mini](https://wiki.mobileread.com/wiki/Kobo_Mini), [Kobo Aura](https://wiki.mobileread.com/wiki/Aura), [Kobo Aura HD](https://wiki.mobileread.com/wiki/Aura_HD) y lectores [Boeye](https://wiki.mobileread.com/wiki/Boeye)
- Formatos: archivos [PDF](https://wiki.mobileread.com/wiki/PDF), [DjVu](https://wiki.mobileread.com/wiki/DjVu), [XPS](https://wiki.mobileread.com/wiki/XPS), [CBZ](https://wiki.mobileread.com/wiki/CBZ), [FB2](https://wiki.mobileread.com/wiki/FB2), [TXT](https://wiki.mobileread.com/wiki/TXT), [HTML](https://wiki.mobileread.com/wiki/HTML), [RTF](https://wiki.mobileread.com/wiki/RTF), [CHM](https://wiki.mobileread.com/wiki/CHM), [EPUB](https://wiki.mobileread.com/wiki/EPUB), [DOC](https://wiki.mobileread.com/wiki/DOC), [MOBI](https://wiki.mobileread.com/wiki/MOBI) y [ZIP](https://wiki.mobileread.com/wiki/ZIP)
- Soporte de [diccionarios](https://wiki.mobileread.com/wiki/Dictionary) mediante StarDict
- Consultas de diccionario en páginas escaneadas: KOReader incluye un motor de [OCR](https://wiki.mobileread.com/wiki/OCR) para reconocer palabras en páginas escaneadas de PDF/DjVu. Para usar el OCR en una página escaneada necesitas instalar los datos de entrenamiento de tesseract para el idioma de tu documento.
- Conexión inalámbrica con [Calibre](https://wiki.mobileread.com/wiki/Calibre)
- Reencuadre (reflow) de PDF complejos mediante [k2pdfopt](https://wiki.mobileread.com/wiki/k2pdfopt)
- Soporte de rotación para el modo horizontal (apaisado)
- Guardado y exportación de notas a archivos o a [Evernote](https://wiki.mobileread.com/wiki/Evernote)
- Fuentes .ttf personalizadas y diccionarios StarDict
- Almacenamiento en la [nube](https://wiki.mobileread.com/wiki/Cloud) (Dropbox, FTP) y sincronización
- Proveedores de contenido: [Wikipedia](https://wiki.mobileread.com/wiki/Wikipedia_mobile_access), [OPDS](https://wiki.mobileread.com/wiki/OPDS) y [Goodreads](https://wiki.mobileread.com/wiki/Goodreads)
- Sincronización del progreso de lectura
- Transporte Zsync
- Complemento de estadísticas
